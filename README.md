# Parley

An LLM chat app (Expo / React Native, TypeScript). The app talks to a small local proxy in `server/` so the API key never ships in the app.

## Scripts

- `npm start` – Expo dev server
- `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test` – quality gates
- `npm run server` – local proxy (added in S01 DEV-2)

Ids: `com.ahmedmu.parley` (iOS bundle id and Android package). Sprint docs live in `docs/sprints/`.
